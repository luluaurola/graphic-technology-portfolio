# 🎨 Calandra's Portfolio Website

Welcome to the repository of **Calandra Alencia Haryani's** personal portfolio website! 
This project is a modern, interactive, and visually striking web portfolio built to showcase creative work, experience, and skills.

## ✨ Key Features

- **Claymorphism Design**: Incorporates the trendy claymorphism aesthetic, providing soft, 3D-like, and tactile UI elements.
- **Dynamic Interactions**: Features interactive elements like a draggable ID lanyard and dynamic character illustrations.
- **Matrix Canvas Effect**: A cool, matrix-style canvas background on the hero section for a futuristic feel.
- **Project Showcase**: A sleek, horizontal scrolling slider to display recent projects and works.
- **Responsive Layout**: Designed to look great across desktop, tablet, and mobile devices.
- **Interactive Contact CTA**: A fun, animated envelope design for the contact section to encourage visitors to reach out.

## 🛠️ Technologies Used

This project is built purely with core web technologies, keeping it lightweight and fast:

- **HTML5**: Semantic markup and structure.
- **CSS3**: Custom styling, claymorphism effects, flexbox/grid layouts, and animations.
- **Vanilla JavaScript**: Logic for the matrix background, interactive dragging, and UI components.
- **Font Awesome (v6)**: Iconography throughout the site.
- **Google Fonts**: Utilizing *Montserrat* and *Nunito* for modern typography.

## 🚀 Getting Started

Since this is a static website, you don't need any complex build tools or servers to run it.

1. **Clone or Download** this repository.
2. Navigate to the project folder.
3. Open `index.html` in your favorite web browser.
   *(Alternatively, you can use a local server like VS Code's "Live Server" extension for a better development experience).*
